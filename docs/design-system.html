Appearance

Surfaces and color

Use the same page background for logs, DNS, and the simulator. Keep rows and panels on that background. Use muted surfaces for chrome, row hover, and table headers. Command buttons use the theme's primary blue; selected switches use #1f72e6 with white text in both themes.

Use green for Allow and success, red for Deny and errors, amber for incomplete results. Pair every status with an icon and a label. Keep status out of page backgrounds.

Type and spacing

Typeface
System sans; system mono for IPs, ports, timestamps, and rules.
Sizes
24px page title, 18px section, 14px body, 12px dense data.
Weights
400 body, 500 switch labels, 600 headings and actions. Sentence case.
Spacing
4px grid; 2px steps inside controls. 8px control gaps, 16px panel padding, 24px section gaps.
Shape
6px controls, 8px panels, 1px borders. No pills or decorative shadows.
Icons
Lucide, 16px in controls, 20px for section actions. Compact switches use 14px icons and 12px checks; omit leading icons first on narrow screens.

Controls

Use Nuxt UI controls. One solid primary action per task. Secondary actions use neutral outlines; utility actions use ghost buttons. Routes use underlined text tabs. Two-choice switches use joined segments in one 30px frame, 12px labels, and a solid blue selected segment with white text. Keep both choices visible and the group width stable. Use size="lg" for 36px action buttons and fields. On small or coarse-pointer screens, use 44px touch targets; extend the hit area around compact switches without enlarging their frame.

Keep labels above fields.
Enter a port from 1 to 65535.

Use a 2px blue focus outline; selected switch segments use a white inset outline. Keep hover, focus, selection, loading, and disabled states distinct. Loading keeps the button label and width. Put field errors below the field and preserve entered values.

Application layout

Keep the 56px app header, brand, route tabs, and account controls consistent. Put source selection and view switches below it; filters and actions follow. Use 16px page insets. The simulator follows configuration, connection, result, then processing order.

Pair each log address with its port, then Action and Protocol. Put Search, Categories, time range, Reset and Run query on the next row; keep Reset and Run together. Log Analytics edits stay pending until Run query. Keep the applied summary and results unchanged during edits and loading. Live Event Hub filters update immediately, without a time range or Run query.

Processing order

DNAT → Network → Application. Show the deciding rule and why evaluation stopped.

Keep tables dense and left-aligned: 12px headers, 44px DNS rows, 64px log rows. Show sort direction. Keep headers visible while scrolling. Open full values in details; make identifiers selectable and copyable.

Feedback and overlays

Put persistent errors and incomplete results beside the affected task. Use toasts for action confirmation. Distinguish no connection, no data, and no filter matches; give each one a useful next action. Show loading in the results area and keep filters usable.

Result incomplete

Resolve missing IP groups before treating the result as conclusive.

Drawers and dialogs use the page surface, a border, and a dimmed backdrop. Include a title and close control. Trap focus, close on Escape, and restore focus to the trigger. Confirm destructive actions with their consequence and an explicit verb.

Categories and time controls use bounded popovers with matching Done buttons. Close popovers on Done, Escape or focus leaving; restore trigger focus on Done and Escape. Edit time inline on phones. Keep every formatted UTC range within a stable trigger width so edits never move the controls.

Responsive and accessible

At 640px and below, start log filters collapsed. Keep the source switch, Edit filters with the draft count, applied connection, action/protocol, UTC range, applied search, result count and Run query visible. For example, Applied · 10.0.1.4 → Any:443. Keep pending changes and validation errors visible. Live mode omits the time range and Run.

Edit filters reveals every field; hiding preserves drafts. Run query collapses the mobile editor and focuses Run. Keep newly edited drafts when a query completes. Escape closes the innermost disclosure first and restores its trigger. Wrap long addresses; show full search values in the editor.

Wrap navigation below the brand and stack expanded fields. Scroll wide tables inside their container; never scroll the whole page horizontally. Maintain 4.5:1 text contrast and 3:1 control and focus contrast in both themes. Label icon buttons, support keyboard operation, announce async results, and respect reduced motion.
